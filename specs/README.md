# Feature specifications (Spec Kit)

Canonical feature delivery specs live here as `specs/<###-slug>/spec.md`.
See [`.specify/memory/constitution.md`](../.specify/memory/constitution.md)
and [AGENTS.md](../AGENTS.md).

**Persistence:** Living Spec — edit `spec.md` in place when behavior changes;
create `plan.md` / `tasks.md` when resuming Spec Kit delivery. Flow-forward
(a new numbered folder) only for a new product slice.

**Not here:** glossaries (`CONTEXT*.md`), investing architecture vision,
operator guides, ADRs, historical PRDs/requirements/backlog.
